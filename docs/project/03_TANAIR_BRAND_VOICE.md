# 03 — TanAir Brand Voice

# TanAir Brand Voice and Product Copy Guide

Version: 1.1
Status: CANONICAL copy guide untuk TanAir Cloud dan semua landing page.
Struktur dia permanen; tukaran kecil ditanda "v1.1 Fix" bawah.  
Primary language: Bahasa Melayu  
Secondary language: English

---

# 1. Brand Personality

TanAir bercakap sebagai pembantu yang:

- Pintar
- Tenang
- Mesra
- Praktikal
- Profesional
- Jujur
- Menghormati pengguna

TanAir bukan:

- Terlalu korporat
- Terlalu formal
- Terlalu manja
- Sarkastik
- Sombong
- Mendesak
- Penuh jargon
- Berpura-pura yakin

---

# 2. Bahasa Utama

Gunakan Bahasa Melayu yang:

- Natural
- Mudah difahami
- Ringkas
- Sesuai untuk pengguna Malaysia
- Tidak terlalu baku
- Tidak terlalu menggunakan slang

English technical terms dibenarkan apabila terjemahan menjadi janggal.

Contoh dibenarkan:

- Chat
- Bot
- Trial
- Token
- Top-up
- Connector
- Admin
- Search
- Upgrade

Pastikan penggunaan konsisten.

---

# 3. Gaya Sapaan

Default:

`Hai`

Onboarding pertama boleh menggunakan:

`Assalamualaikum!`

Gunakan sapaan agama hanya pada onboarding yang telah dipersetujui.

Jangan membuat andaian agama pengguna dalam mesej lain.

---

# 4. Kata Ganti Nama

TanAir merujuk dirinya sebagai:

`Aura`

Contoh:

`Aura boleh bantu susunkan langkah seterusnya.`

Default untuk pengguna:

`anda`

Mode santai atau bot tertentu boleh menggunakan:

`awak`

Jangan bertukar antara `anda`, `awak`, `kau` dan `boss` tanpa sebab.

---

# 5. Panjang Copy

Buttons:

- 1 hingga 4 perkataan

Headings:

- Pendek dan berorientasikan tindakan

Helper text:

- Satu atau dua ayat

Error:

- Nyatakan masalah
- Nyatakan cara membaiki

Modal:

- Jangan melebihi keperluan
- Elakkan dinding teks

---

# 6. Emoji

Emoji digunakan secara sederhana.

Sesuai untuk:

- Empty state
- Toast kejayaan
- Friendly demo
- Trial countdown

Tidak sesuai untuk:

- Audit log
- Security warning kritikal
- Billing failure serius
- Admin tables
- Semua button

Utamakan SVG icons untuk interface utama.

---

# 7. CTA

CTA utama perlu berorientasikan hasil.

Gunakan:

- Mula Berchat
- Cuba TanAir
- Bina Bot
- Cipta Bot
- Simpan Perubahan
- Naik Taraf
- Lihat Pelan
- Tambah Kuota

Elakkan:

- Submit
- Proceed
- Click Here
- Execute
- Confirm Action

Kecuali dalam context teknikal yang benar-benar memerlukannya.

---

# 8. Error Messages

Format:

```text
Apa yang berlaku.
Apa yang pengguna boleh lakukan.
```

Contoh:

`Mesej belum dapat dihantar. Semak sambungan anda dan cuba lagi.`

Bukan:

`Error 500.`

Jika correlation ID tersedia:

`Rujukan: abc-123`

Jangan dedahkan:

- Stack trace
- Raw API response
- Secret
- Internal endpoint
- System prompt

---

# 9. Trial Copy

Badge:

`Trial Pro: 2 hari 14 jam lagi`

Expiry heading:

`Trial anda sudah tamat`

Supporting copy:

`Anda masih boleh menggunakan Chat. Naik taraf untuk meneruskan Trade dan Image.`

CTA:

`Lihat Pelan Pro`

Jangan gunakan bahasa menakutkan atau memalukan pengguna.

---

# 10. Quota Copy

Warning:

`Kuota Chat anda hampir penuh.`

Critical:

`Kuota Chat tinggal 5%.`

Full:

`Kuota bulan ini sudah digunakan sepenuhnya.`

Options:

- Tambah 50,000 token
- Tambah 150,000 token
- Lihat pilihan naik taraf

Avoid:

`Anda telah melanggar limit.`

---

# 11. Memory Copy

Chip:

`Aura ingat 3 perkara`

Panel title:

`Memori Aura`

Subtext:

`Anda boleh menyemak dan memadam memori pada bila-bila masa.`

Suggestion:

`Aura boleh ingat perkara ini untuk perbualan akan datang.`

Actions:

- Simpan
- Edit
- Abaikan
- Padam

Never say:

`Aura tahu semua tentang anda.`

---

# 12. Bot Builder Copy

Use outcome-oriented language.

Step names:

1. Identiti
2. Cerapan dan Skills
3. Sambungan dan Jadual

Description prompt:

`Apa tugas utama bot ini?`

Schedule prompt:

`Apa yang bot perlu lakukan?`

Completion:

`Bot anda sudah bersedia.`

---

# 13. Upgrade Copy

Upgrade messaging must be:

- Clear
- Respectful
- Non-manipulative
- Transparent about price
- Transparent about capability

Example:

`Video tersedia dalam pelan Empire.`

CTA:

`Lihat Pelan Empire`

Avoid:

- “Anda rugi jika tidak upgrade”
- Fake countdown
- False scarcity
- Preselected payment choices
- Difficult cancellation language

---

# 14. Trust Copy

Prototype:

`Data prototaip disimpan pada peranti anda.`

Deletion:

`Padam data anda pada bila-bila masa.`

Privacy:

`Data anda tidak dijual.`

Only use verified production claims.

---

# 15. Trade and Financial Copy

TanAir must not guarantee:

- Profit
- Price increase
- Investment return
- Trading success

Use language such as:

- Analisis
- Pemerhatian
- Senario
- Risiko
- Data yang tersedia
- Pertimbangkan untuk mendapatkan nasihat profesional

For simulated landing demo:

`Contoh respons simulasi. Ini bukan data pasaran langsung.`

# 18. Copy Review Checklist

Before shipping copy, verify:

- [ ] Bahasa mudah difahami
- [ ] Tiada jargon tidak perlu
- [ ] Tindakan seterusnya jelas
- [ ] Harga dinyatakan dengan telus
- [ ] Feature simulasi dilabel
- [ ] Tiada dakwaan tidak disahkan
- [ ] Tiada jaminan kewangan
- [ ] Tiada dark pattern
- [ ] Tidak terlalu banyak emoji
- [ ] Istilah konsisten
- [ ] Sesuai untuk skrin kecil
- [ ] Error membantu pengguna

# 19. v1.1 Improvement Notes (20Sep)

Perubahan oleh TanAir (DevOps audit):

- **BM conventions:** Nama produk/TanAir, Brand "TanAir by Norliv
  Labs" — guna ejaan standard Malaysia, tiada penatah British en-GB.
- **CTA "Bina Bot" vs "Cipta Bot"**: gunakan SATU je sepanjang UI —
  pilih "Bina Bot" (lebih BM-natural). Kedua-dua tak boleh muncul
  serentak dalam sesi yang sama.
- **Error + correlation id**: format Rujukan: `abc-123` cukup, TAPI
  jangan paparkan correlation ID kalau itu internal/UUID raw — mask
  dulu 6-char pertama sahaja.
- **Awak / Anda**: pilih AWAK untuk landing + chat santai fnDefault;
  "anda" kekalkan untuk Billing, Admin, Security contexts (formal).
- **Anti-dark-pattern** telah jadi hard rule (Amira = trade copy pun
  no guaranteed-return language).
- Bahasa figure tidak digunakan untuk label UI-control (button,
  nav, input label) — BM je. English figure hanya untuk body copy
  teknikal.
